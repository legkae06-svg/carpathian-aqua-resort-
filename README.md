# carpathian-aqua-resort-
Інформаційна система управління котеджним містечком та аква-термальним комплексом «Carpathian Aqua-Resort &amp; Spa System»

## Основні завдання системи
- Унеможливлення подвійного бронювання котеджів (овербукінгу).
- Пакетне погодинне планування сеансів аква-термального комплексу та чанів.
- Консолідація всіх послуг (проживання, спа, прокат спорядження, доставка харчування і дров, джипінг) у єдиному рахунку гостя.
- Оперативна синхронізація між рецепцією та службою клінінгу.
